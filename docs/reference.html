Reference

Everything in the library

Numbers can be JS numbers (read by their shortest spelling, so 0.1 is 110\tfrac{1}{10}101​), bigints, strings such as "3/4" or "1.25", or Core Rationals. Functions marked R return a Refinement: .quick.value is the float sketch; .exact() or await .settle() give the certified result.
