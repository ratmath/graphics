Reference

Everything in the library

Numbers can be JS numbers (read by their shortest spelling, so 0.1 is \(\tfrac{1}{10}\)), bigints, strings such as "3/4" or "1.25", or Core Rationals. Functions marked R return a Refinement: .quick.value is the float sketch; .exact() or await .settle() give the certified result.

Viewports and Refinements

NameWhat it does
viewport({ x: [a, b], y: [c, d], width, height })Exact rational world rectangle over a pixel grid; dx, dy are exact.
Refinement, live(compute, onStage, { idleMs, sliceMs, onProgress })The fast-then-exact protocol shared with linalg and analytic; live wires it to input.
precisionFor(vp), columnRationals(vp, i)Working precision for a viewport; the exact x-interval of a pixel column.
