Regions and inequalities

Shade where a condition holds. Inequalities can be chained and joined with and, or and not. Regions bounded by lines are computed exactly, corners included; everything else is certified pixel by pixel.

Writing conditions

"x^2 + y^2 < 4"                    // one comparison
"0 <= x <= 3"                      // chains mean "and"
"y >= x and x + y <= 4"            // also &&, ||, !, and a comma for "and"
"(y > 1 or y < -1) and x > 0"      // parentheses group logic
"x != y"                           // ≤ ≥ ≠ work too

parseCondition(text) gives the tree; each comparison is normalized to \(F < 0\), \(F \le 0\), \(F = 0\) or \(F \ne 0\).

Bounded by lines: exact polygons

When every comparison is affine in \(x\) and \(y\) with rational coefficients, region(...).exact() splits the condition into "and" pieces, clips the viewport rectangle by each piece's half-planes with exact arithmetic, and returns

  • pieces: convex polygons with rational vertices and exact areas,
  • boundary: the outer edges, each marked strict (from \(<\) or \(>\), drawn dashed) or not (solid). Edges shared by two pieces of a union are dropped,
  • corners: points where two boundary lines meet, each with included, drawn as a filled or open dot, and
  • lines: segments from equations such as x - y = 1 and x >= 0.
const vp = viewport({ x: [-5, 5], y: [-4, 4], width: 400, height: 320 });
const r = region("3x + 7y <= 5, x - 2y >= -1, y >= -1/3", {}, vp).exact();
r.corners.map((c) => String(c.point));   // ["(22/9, -1/3)", "(3/13, 8/13)", "(-5/3, -1/3)"]
String(r.pieces[0].area);

Anything else: certified pixels

For other conditions the viewport is classified box by box with interval arithmetic, as for implicit curves. Each comparison is true on the whole box, false on the whole box, or undecided; and, or and not combine those three values, and decided parts are dropped as boxes shrink. The result lists inside rectangles, proven to lie entirely in the region, and boundary pixels that stay undecided. Every other pixel lies entirely outside. Where a function is undefined, such as \(\sqrt{x}\) for \(x < 0\), the condition is false.

const s = region("x^2 + y^2 < 9 and y > x^2 - 4", {}, vp).exact();
s.kind;       // "region"
s.inside;     // [x, y, w, h, ...] pixel rectangles, proven inside
s.boundary;   // per column, rows still undecided

To force the pixel method for a linear condition, pass { method: "pixels" }.
